## TL;DR

litl (**L**ightweight **I**n**T**erface for **L**ossy compression) is a small Python framework I built for writing and comparing lossy compressors. You write a compressor as a single class, and litl gives you a command-line tool, a file format, and quality metrics for free. It is one `pip install litl` away.

## Problem

Every lossy compressor ships with its own scripts, its own file format, and its own idea of how to measure quality. Comparing a neural compressor against a classic one, like SIREN against TTHRESH in my [INR blog post](/blog/inr), means writing the same glue code again and again: load the data, time the run, compute PSNR and SSIM, work out the compression ratio.

I wanted to write that glue once.

A compressor only has to answer two questions: how do I turn data into a blob, and how do I get the data back? Here is a complete one that rounds every value to 8 bits:

```python title="quantize.py"
import numpy as np

from litl import DataWrapper
from litl.blobs import ArrayBlob
from litl.compressors import Compressor, CompressorAbout


class Quantize(Compressor):

    @classmethod
    def about(cls):
        return CompressorAbout(name="Quantize", description="Rounds every value to 8 bits", version="1.0.0")

    @classmethod
    def blob_class(cls):
        return ArrayBlob

    @classmethod
    def compress(cls, data: DataWrapper, config: dict):
        array = data.numpy()
        low, high = float(array.min()), float(array.max())
        step = (high - low) / 255

        quantized = np.round((array - low) / step).astype(np.uint8)
        return ArrayBlob(quantized), {"min": low, "step": step}

    @classmethod
    def decompress(cls, blob: ArrayBlob, meta: dict):
        array = blob.array * meta["step"] + meta["min"]
        return DataWrapper(array.astype(np.float32))
```

A blob can be an array, raw bytes, or a whole PyTorch model, so the "compressed file" can literally be a neural network.

## The .litl file

Whatever your compressor returns gets wrapped into a `.litl` file, together with everything needed to open it again later: which compressor made it, which version, and its settings.
